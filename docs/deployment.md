# 部署与运维指南

适用版本：1.1.0 · 平台：Windows 10/11 x64

## 1. 安装

安装包：`LCCompliance-Setup-1.1.0.exe`（约 177 MB，NSIS）。

| 项目 | 说明 |
|---|---|
| 安装范围 | **每用户安装**，不需要管理员权限。默认目录 `%LOCALAPPDATA%\Programs\…`，向导里可改 |
| 静默安装 | `LCCompliance-Setup-1.1.0.exe /S`；指定目录加 `/D=C:\目标目录`（`/D=` 必须是最后一个参数，路径不加引号） |
| 静默安装后 | **不会**自动启动应用，适合 SCCM / Intune 等批量部署 |
| 快捷方式 | 开始菜单、桌面 |
| 静默卸载 | 运行安装目录下的 `Uninstall LCCompliance.exe /S` |
| 卸载时的用户数据 | **不会删除** `%APPDATA%\LCCompliance`（加密数据库与密钥）。需要彻底清除时请手工删除该目录 |

### 代码签名（需要你们提供证书）
当前安装包**未签名**：Windows SmartScreen 会提示"未知发布者"。企业部署前建议用公司的代码签名证书签名：

```powershell
$env:CSC_LINK = "C:\certs\company.pfx"        # 或 base64 内容 / https 地址
$env:CSC_KEY_PASSWORD = "<证书口令>"
npm run dist -w @lc/desktop
```

没有证书时，可让 IT 通过组策略把安装包加入受信任来源，或用 SCCM 推送（推送的软件不触发 SmartScreen 提示）。

## 2. 数据与安全

数据目录：`%APPDATA%\LCCompliance`

| 文件 / 目录 | 内容 |
|---|---|
| `lc.db` | 加密数据库（SQLite，敏感列为 AES-256-GCM 密文）；含国别规则表 `country_rules`（备注与要求为密文），随数据库一起备份与恢复 |
| `keystore.json` | 数据密钥，**经 Windows DPAPI 加密**，只有同一个 Windows 用户能解开 |
| `backups\auto\` | 自动本地快照（每天首次启动后一份，默认保留 7 份） |
| `backups\pre-restore-*` | 恢复备份时被替换下来的原有数据，及对应的旧密钥文件 |
| `ocr-lang\` | OCR 语言包（首次使用时从安装目录复制） |

### 加密范围
**加密：** 案件名与信用证编号、信用证报文、交单数据、单据原文与文件名、AI 抽取结果、审查结果、手册原文与检查项、外发日志、审计日志明细。
**不加密（元数据）：** ID、时间戳、状态、字数/页数统计、规则 ID、设置项（如界面语言、模型名）。
API Key 单独经 DPAPI 保护，不在数据库明文里。

> 安全边界：这是**字段级加密**，防的是"数据库文件被复制走"。它不防已经登录到该 Windows 账户的人，也不防能在内存里读取进程的恶意软件。启用 BitLocker 做整盘加密是合理的补充。

### 密钥与恢复——必须读
密钥绑定 **Windows 用户账户**。以下情况会导致数据无法打开：重装系统、换电脑、换 Windows 用户、重置密码后丢失 DPAPI 主密钥。
此时应用进入**锁定恢复界面**（不改动任何数据），只能从**口令加密备份**恢复。

- 设置 → 数据与备份 → **导出加密备份**：生成 `.lcbak` 文件，里面连同数据密钥一起用口令加密，**可在另一台电脑上仅凭口令恢复**。
- 口令丢失**无法找回**。请记录到公司密码管理工具。
- **自动快照不能跨电脑恢复**（依赖本机密钥），它防的是文件损坏和误删。
- 建议：每月做一次加密备份；应用在超过 30 天未备份时会提醒。

### 恢复步骤
1. 设置 → 数据与备份 → 从备份恢复（锁定界面里也有同样的入口）
2. 输入备份口令，选择 `.lcbak` 文件
3. 应用先完整校验：口令正确、文件未被改动、库结构、审计链、所有加密内容可解开
4. 确认后替换并重启。**原有数据不会被删除**，保存在 `backups\pre-restore-*.db`，对应旧密钥在 `backups\keystore.pre-restore-*.json`

### 从旧版本升级
旧版本数据在 `%APPDATA%\@lc\desktop`。首次启动新版时会**移动**（不是复制）到新目录并整体加密，旧位置不留明文数据库。加密在一个事务里完成并逐值回读校验，失败则整体回滚。

## 3. 企业策略

策略文件：`%ProgramData%\LCCompliance\policy.json`（机器级，建议只给管理员写权限）。修改后无需重启，几秒内生效。文件不存在则全部使用默认值；写错的项会被忽略并在设置 → 更新页给出警告，不会导致应用无法使用。

```json
{
  "update": {
    "enabled": true,
    "feedUrl": "https://updates.corp.example/lc/",
    "autoCheck": true
  },
  "ai": {
    "allowed": true
  }
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `update.enabled` | `true` | `false` 时完全禁用更新 |
| `update.feedUrl` | 无 | 更新源目录。**必须是 HTTPS**，不允许带账号口令。未配置则不检查更新 |
| `update.autoCheck` | `true` | 启动后与每 6 小时自动检查；`false` 则只能用户手动检查 |
| `ai.allowed` | `true` | `false` 时**禁止使用外部 AI**：设置里的开关被锁定，单据与手册文字不会外发，也不能联网获取模型列表 |

更新源只能由策略设定，用户在应用内无法修改。

## 4. 发布更新

### 构建
```powershell
# 国内网络下载 electron / NSIS 工具时建议使用镜像
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"

# 先改 apps/desktop/package.json 的 version（如 1.0.1）
npm run dist -w @lc/desktop
```
产物在 `apps/desktop/release/`：`LCCompliance-Setup-<版本>.exe`、`.exe.blockmap`、`latest.yml`。

### 发布
把上面三个文件放到 `update.feedUrl` 指向的目录（任意 HTTPS 静态文件服务即可，如 IIS、Nginx、对象存储）。**`latest.yml` 最后上传**，客户端以它为入口。
`latest.yml` 里有安装包的 sha512，客户端下载后会校验，不一致则拒绝。

### 客户端体验
1. 设置 → 更新 → 检查更新（或自动检查）→ 提示"发现新版本"
2. 用户点"下载更新"（**不会**自动下载）
3. 下载完成后点"重启并安装"（**不会**自动重启，避免打断正在进行的工作）
4. 用户数据不受影响

### 回滚
应用不允许降级安装。需要回滚时：卸载当前版本，安装旧版安装包（用户数据保留）。数据库结构只会向前迁移，旧版可能无法打开被新版迁移过的数据，回滚前先导出加密备份。

## 6. 故障排查

| 现象 | 原因与处理 |
|---|---|
| 启动后显示"无法解锁数据" | 密钥读不出（换了用户/电脑）、密钥文件丢失或不匹配。点"从备份恢复"。没有备份则无法找回 |
| "系统加密不可用"后退出 | Windows DPAPI 不可用。应用**拒绝**退化为明文存储。检查用户配置文件是否正常加载 |
| 设置 → 更新显示"管理员尚未配置更新源" | `policy.json` 缺少 `update.feedUrl`，或该值不是 HTTPS |
| 更新页提示"策略文件无法解析" | `policy.json` 不是合法 JSON，已被忽略；修正后几秒内生效 |
| 想确认数据库没被动过 | 设置 → 数据与备份 → 检查数据库完整性 |
| 第二次启动没反应 | 单实例保护：同一数据目录只允许一个实例，已有实例会被激活到前台 |

## 7. 使用指南的维护

面向非专业用户的使用指南内置在应用里（侧栏「使用指南」、顶部「帮助」菜单、F1；首次启动自动弹出一次）。内容在 `apps/desktop/src/renderer/src/guide-content.ts`，中英文各一份。

- 指南里提到的按钮、页签名称写成 `{{字典键}}`，显示时自动替换为界面上的真实文案，**改界面文字时指南会同步**。
- 测试（`npm test -w @lc/desktop`）会检查：引用的字典键都存在、中英文结构一致、没有残留占位符、必须的提醒（"这只是自查工具""未检查不等于通过""没备份无法找回"）没有被删掉。
- **新增或改动功能时，请同步更新指南**；测试只能保证文字与界面对得上，不能保证指南写到了新功能。
